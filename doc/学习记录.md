### Git 操作顺序

1. `git init` — 初始化本地仓库
2. `git add .` — 将所有文件加入暂存区
3. `git commit -m "first commit"` — 第一次提交
4. 修改 `Core/Src/main.c` 中的 `BLINK_TIMES` 从 `3U` 改为 `5U`
5. `git add Core/Src/main.c` — 将修改加入暂存区
6. `git commit -m "将闪烁次数调整为5"` — 第二次提交
7. `git checkout -b feature-blink` — 创建并切换到新分支
8. 在 `feature-blink` 分支上修改 `blink_led()` 的延时参数并提交
9. `git checkout main` — 切换回主分支
10. `git merge feature-blink` — 合并分支
11. `git reset --hard HEAD~1` — 回退一次提交（在练习分支上操作）
12. `git remote add origin https://github.com/wjq-817/hello-word-xuezhang.git` — 关联远程仓库
13. `git push -u origin main` — 推送到远程仓库

### 常用 Git 命令

| 命令 | 作用 | 什么时候用 |
|------|------|------------|
| `git init` | 初始化一个新的 Git 仓库 | 开始用 Git 管理一个新项目时 |
| `git add <file>` | 将文件改动加入暂存区 | 修改完代码，准备提交之前 |
| `git commit -m "<msg>"` | 将暂存区的改动提交到本地仓库 | 完成一个阶段性修改，需要保存快照时 |
| `git checkout -b <name>` | 创建并切换到新分支 | 要开发新功能或做实验性修改，不想影响主分支时 |
| `git merge <branch>` | 将指定分支合并到当前分支 | 功能开发完成，需要合入主分支时 |
| `git push` | 将本地提交推送到远程仓库 | 想把本地代码同步到 GitHub 时 |
| `git reset --hard HEAD~1` | 回退到上一次提交，丢弃所有改动 | 提交错了或者想撤销最近一次提交时 |
